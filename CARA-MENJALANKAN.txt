CARA MENJALANKAN WEBSITE EMOTION CHECK-IN
==========================================

PENTING: Jangan buka file index.html dengan double-click.
Kamera & model TIDAK akan berfungsi pada protokol file://

LANGKAH:
1. Buka PowerShell / Command Prompt.
2. Masuk ke folder ini:
   cd path\ke\emotion-checkin
3. Jalankan server lokal (pilih salah satu):
   - Jika punya Python:  python -m http.server 8000
   - Jika punya Node.js: npx serve
4. Buka browser (Chrome/Edge) ke:
   http://localhost:8000
5. Izinkan akses kamera saat diminta.

STRUKTUR FILE:
- index.html       Halaman pilih nama
- checkin.html     Halaman scan & konfirmasi
- tentang.html     Halaman penjelasan proyek
- css/style.css    Semua styling
- js/siswa.js      Daftar siswa (bisa diedit)
- js/app.js        Logika halaman awal
- js/checkin.js    Logika scan & konfirmasi
- models/          Model deteksi (4 file)

PRIVASI:
Tidak ada data yang disimpan. Semua proses on-device.
